# Ассеты

Главная нагрузка на художника — коты; фоны и интерфейс намеренно простые. Пока ассетов нет, код работает на заглушках из `public/assets/placeholder/`.

## Арт

| Что | Кадры и варианты | Примечание |
| --- | --- | --- |
| Барабанщик | idle, hit | |
| Long Cat | body + мусорный бак отдельным спрайтом | бак рисуется поверх кота |
| Keyboard Cat | body + «выглядывает» из-за укрытия | |
| Тыква-кот | body + светящаяся тыква отдельным слоем | тыква видна в блэкауте |
| Котёнок хора | 1 спрайт | 4 котёнка = один спрайт с разной окраской (tint); на сцене — общий «хорокот» |
| Кот-трубач | idle, blow | |
| Pop Cat | sleep, closed, open, trip | |
| Bongo Cat | paw_left, paw_right | уже отрисован |
| Помощник | портрет для диалогов | кто это — решить |
| Фоны | офис, сцена, 16 камер | камеры — заливка + 1–2 силуэта |
| Интерфейс | иконки клаксона и УФ | можно inline SVG |

- PNG с прозрачностью, высота кота ~512 px.
- Ноги кота у нижнего края картинки (туда ставится точка опоры деформации).
- Одинаковая толщина контура у всех котов.
- Путь: `public/assets/cats/<catId>/<frame>.png`, например `cats/bongo/paw_left.png`. Ключ текстуры в коде — `<catId>/<frame>`.

## Музыка

- Один BPM на весь трек (118–124), размер 4/4, луп 16 тактов. **Пока не утверждено — значения берутся из `src/data/stems.ts`.** Заглушки: 120 BPM, 16 тактов (32 с).
- Восемь стемов одной длины с одной точки старта: `drums`, `bass`, `keys`, `pumpkin`, `choir`, `trumpet`, `pop`, `bongo`.
- Экспорт из FL: Split mixer tracks, хвосты — Wrap remainder; OGG 44,1 кГц + запасной MP3.
- Каждый стем звучит сам по себе; тройка `drums + bass + keys` — законченный грув.
- Труба: фраза раз в 2 такта длиной 1 такт (на это завязана загадка).
- Сайдчейн впекается в стемы.
- Путь: `public/assets/audio/stems/<stemId>.ogg` (+ `.mp3`).

## Звуковые эффекты

`horn`, `found` (фанфара), `static` (помехи переключения), `uv` (щелчок), `snore`, `kitten`, `keys_warmup`, `blackout`. Путь: `public/assets/audio/sfx/<id>.ogg`. Всё своё или сильно переработанное.

## Заглушки

- `public/assets/placeholder/cat_a.svg`, `cat_b.svg` — силуэт кота, кадр «рот закрыт / открыт». Используются для любого кота, пока нет арта.
- Стемы-заглушки генерируются скриптом `npm run gen:placeholders` в `public/assets/audio/placeholder/` (WAV, не коммитятся). Описание синтеза — в задаче 01.
