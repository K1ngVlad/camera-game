# Ассеты

**Правило: положил файл с правильным именем в `src/assets/` — он появился в игре.** Ассеты находятся при сборке через `import.meta.glob`; если файла нет, используется заглушка. Код ради нового спрайта или трека не меняется. Список недостающих ассетов виден в песочнице (`?dev=1`) и одной строкой в консоли.

## Структура

```
src/assets/
  cats/<catId>/<frame>.png          longcat/body.png, bongo/body.png, popcat/open.png
  props/<name>.png                  bin.png, bin_lid.png, pumpkin_glow.png
  portraits/assistant/<frame>.png   closed.png, open.png
  backgrounds/<name>.png            cam_06.png, stage.png, office.png, menu.png
  audio/camera/<catId>.ogg|.mp3     камерные лупы
  audio/song/<catId>.ogg|.mp3       стемы песни сцены
  audio/sfx/<id>.ogg|.mp3           horn, found, static, uv, blackout
```

`catId`: `drummer`, `longcat`, `keyboard`, `pumpkin`, `choir`, `trumpet`, `popcat`, `bongo`, `cattlecat`. Имена файлов — латиница в нижнем регистре.

## Арт

- PNG с прозрачностью. Кот — высота ~512 px, ноги у нижнего края, кадр обрезан по фигуре.
- **Все кадры одного кота — одинакового размера холста**, иначе кот «прыгает» при смене кадра.
- Размер на экране задаёт игра (`displayHeight` в конфиге), так что художнику не нужно подгонять масштаб между котами.
- Одинаковая толщина контура у всех котов (например, 8 px при высоте 512).
- Имена кадров должны совпадать с `anim.frames` в `src/data/cats.ts`. Один кадр — `body.png`; два — `closed.png` / `open.png` (рот) или `left.png` / `right.png` (лапы).

## Музыка

Песня сцены:

- 120 BPM, 4/4, **34 такта** (68 с) (вступление и концовка включены). Какие такты зацикливать — `loopStartBar` / `loopEndBar` в `src/data/music.ts`.
- Один стем на кота, все **ровно одной длины и с одной точки старта** (Split mixer tracks в FL, от начала проекта до конца 34-го такта).
- Хвосты ревёрба на шве петли: если петля — вся песня, Wrap remainder; если петля внутри песни, хвосты остаются как есть.
- Бас, кик, тыква — моно; остальные можно стерео (бюджет памяти — `docs/audio.md`).
- Сайдчейн впекается в стемы.

Камерные лупы:

- Отдельный короткий файл на кота, 2–8 тактов, тот же BPM, начинается ровно на сильную долю, бесшовный.
- Должен звучать **сам по себе непрерывно** — по нему игрок ищет кота на слух. Хорошо, если это узнаваемый фрагмент его партии из песни.
- Для загадок: трубач — фраза 1 такт раз в 2 такта (луп 2 или 4 такта); Pop Cat — храп; Keyboard Cat — «разминка».
- Если у лупа другой BPM или длина, это указывается в `src/data/music.ts`.

## Звуковые эффекты

`horn`, `found` (фанфара), `static` (помехи переключения), `uv` (щелчок), `blackout`. Всё своё или сильно переработанное. Реплики помощника озвучиваются синтезированными «блипами», файлы не нужны.

## Заглушки

- Арт: `public/assets/placeholder/cat_a.svg`, `cat_b.svg` с подкраской `tint` из конфига кота.
- Звук: `npm run gen:placeholders` генерирует в `public/assets/audio/placeholder/` камерные лупы (`camera/<catId>.wav`, 4 такта) и стемы песни (`song/<catId>.wav`, 34 такта), не коммитятся.

## Как добавить свой ассет

**Картинку:**

1. Положи исходник в `art-src/` по пути `cats/<catId>/body.png` (или нужный кадр).
2. Запусти `npm run art` — скрипт обрежет, отмасштабирует и сохранит в `src/assets/`.
3. Открой песочницу (`?dev=1` в dev-сервере), нажми «Нажми, чтобы начать» и убедись что в таблице Asset report колонка Art показывает `art`, а не `stub`.

**Звук:**

1. Положи файл в `src/assets/audio/camera/<catId>.wav` (или `.ogg`/`.mp3` для камерного лупа) или `src/assets/audio/song/<catId>.wav` для стема песни.
2. Перезапусти dev-сервер (`npm run dev`).
3. В песочнице проверь таблицу Asset report: колонка Len должна показывать `✓`, иначе длина файла расходится с ожидаемой — смотри предупреждение в консоли.
