# Визуальный стиль интерфейса

Макеты всех экранов: [канвас «Purr-veillance — экраны»](https://claude.ai/artifact/SkeDv7M8wLbNCc8ijQEWsB) (главное меню, офис, камеры — кликабельный прототип, сцена, диалог, попап находки). Если есть доступ к макету — сверяйся с ним; ниже — выжимка.

## Основа

- Игровое поле фиксированное **1280×720 (16:9)**, масштабируется целиком под окно с сохранением пропорций (letterbox, фон `#12111A`).
- Ночная тёмно-фиолетовая база, «игровые» кнопки с толстым тёмным контуром и тенью-подложкой, мягкие скругления. Ориентир — Battle Cats: просто, контрастно, весело.

## Шрифты (Google Fonts, с кириллицей)

- **Unbounded** 600/800 — заголовки и главные кнопки.
- **Rubik** 400/500/700 — текст.
- **IBM Plex Mono** 400/600 — интерфейс камер, таймкоды, счётчики.

## Компоненты

- **Главная кнопка:** фон `accent`, контур 3 px `bg-deep`, радиус 16, `box-shadow: 0 6px 0 accent-shadow`, Unbounded 800. При нажатии — сдвиг вниз на 4 px и тень 2 px.
- **Вторичная кнопка:** прозрачная, рамка 2 px `line`, Rubik 500.
- **Кнопка камеры:** 72 px высотой; открытая — `panel-alt` + рамка `line`; выбранная — рамка `cam`, текст `cam`; заблокированная — пунктир, иконка замка, `disabled`.
- **Кадр камеры:** тёмная рамка, внутри плашки на `rgba(10,10,16,0.6)`: «CAM 06 · Название» слева сверху, «● REC» справа сверху, таймкод слева снизу, «УФ-РЕЖИМ» справа снизу. Сканлайны и шум — фильтрами Pixi.
- **Диалог:** панель цвета `text` с тёмным текстом внизу экрана, портрет слева в янтарной рамке, курсор печати.
- **Попап находки:** карточка цвета `text` по центру на затемнении, круглый янтарный «медальон» с котом, штамп для особых котов — красная рамка, наклон 12°.

## Доступность

Все кнопки — настоящие `<button>`, иконки с `aria-label`, контраст текста не ниже 4.5:1.
