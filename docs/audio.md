# Звук и анимация от амплитуды

Звук разделён на две независимые части:

- **Камерный луп** — короткий отдельный трек у каждого кота (2–8 тактов). На экране камер звучит **только луп искомого кота**, громкость зависит от камеры. Это же его «голос» для загадок: храп Pop Cat, разминка Keyboard Cat, фраза трубача, мелодия Bongo Cat.
- **Песня сцены** — полная песня, разложенная на стемы по котам. Звучит на сцене (партии найденных котов в полную силу) и тихо в меню и офисе.

Анимация кота всегда берёт амплитуду из того трека, который сейчас звучит для этого кота: на камере — из камерного лупа, на сцене — из его стема песни.

## Что где звучит

| Где игрок | Камерный луп искомого кота | Песня сцены |
| --- | --- | --- |
| Меню | — | **все** включённые стемы, gain 0.18, cutoff 900 (тизер) |
| Офис | — | стемы **найденных**, gain 0.22, cutoff 700 («клуб за стеной») |
| Камеры: камера кота | gain 1.0, открыт | остановлена (fade-out 0.5 с) |
| Камеры: соседняя | gain 0.3, cutoff 800 | остановлена |
| Камеры: дальше | 0 | остановлена |
| Сцена | — | стемы найденных 1.0, остальные 0; **при входе песня начинается сначала** (fade-in 0.3 с) |

Значения стартовые. Особые случаи (задача 04+): Bongo Cat на камерах-«эхо» — gain 0.15, cutoff 1500; хор — луп котят слышен на камере любого несобранного котёнка.

Переход меню → офис не перезапускает песню, только меняет микс. Переход на сцену — перезапуск с начала. Уход на камеры — песня гаснет и останавливается.

## Треки

```ts
interface TrackTiming {
  bpm: number
  beatsPerBar: number
  bars: number            // полная длина файла в тактах
  loopStartBar?: number   // по умолчанию 0
  loopEndBar?: number     // по умолчанию bars
}
```

- Трек играется с начала; дойдя до `loopEndBar`, возвращается на `loopStartBar` (`source.loopStart/loopEnd`, вычисленные из тактов, а не из длины файла). Так вступление звучит один раз, а середина крутится.
- Чистая функция `trackTime(elapsed, timing)` → секунда внутри файла с учётом вступления и петли; `positionAt(...)` → такт/доля. Обе с тестами.
- **Песня сцены:** 120 BPM, 4/4, 34 такта (68 с). Границы петли — в `src/data/music.ts` (пока `0..34`, уточнит композитор).
- **Камерные лупы:** у каждого свои `bpm/bars` (обычно 120 BPM, 2–8 тактов), петля на весь файл.

## Граф

```
камерный луп: Source(loop) → Filter(lowpass) → Gain ─┐
стемы песни:  Source(loop) → Filter → Gain ─→ songBus(Gain) ─┤
SFX и «голос» помощника:  Source/Osc → Gain ─→ sfxBus ───────┤
                                                              └→ Compressor (лимитер) → destination
```

- Стемы песни стартуют одним вызовом с общим `t0`. Остановка песни — fade-out `songBus`, затем `stop()` источников; следующий запуск создаёт новые источники (буферы переиспользуются).
- Камерный луп: в каждый момент активен максимум один. Смена искомого кота — crossfade 0.3 с.
- Все изменения громкости — `setTargetAtTime(..., 0.05)`; fade-in/out — `linearRampToValueAtTime`.
- `AudioContext` создаётся/возобновляется по жесту («Играть» или первый клик по меню).

## Публичный API (`src/audio/AudioEngine.ts`)

```ts
type TrackId = string            // 'cam:longcat', 'song:longcat', 'sfx:horn'

class AudioEngine {
  load(manifest: AudioManifest, onProgress?): Promise<void>
  start(): Promise<void>
  readonly started: boolean

  setCameraLoop(state: { catId: CatId; gain: number; cutoff: number } | null): void
  setSong(state: { playing: boolean; restart?: boolean; busGain: number; cutoff: number;
                   gains: Partial<Record<CatId, number>> }): void

  playSfx(id: string, opts?: { gain?: number; detune?: number }): void
  blip(opts: { freq: number; duration: number; gain: number }): void   // «голос» помощника

  getAmplitude(trackId: TrackId): number   // огибающая в текущей позиции × текущая громкость, 0..1
  isOnset(trackId: TrackId): boolean
  getPosition(trackId: TrackId): MusicPosition | null   // null, если трек не играет

  onBeat(cb) / onBar(cb)   // по «активным часам»: на камерах — луп искомого кота, иначе — песня
  update(): void           // раз в кадр
}
```

## Микшер (`src/audio/mixer.ts`)

Чистая функция `computeAudioState(input) → { camera, song }` по таблице выше, где `input = { screen, camera, found, currentCat }`. Привязка к store (`bindMixer.ts`) вызывает `setCameraLoop` / `setSong` только при изменении результата; `restart: true` — только в момент входа на сцену.

## Огибающие (`src/audio/envelope.ts`)

Считаются для каждого трека после декодирования: моно-сведение → RMS по окнам ~10 мс → нормализация по 98-му перцентилю → сглаживание (атака ~10 мс, спад ~120 мс) → onsets с гистерезисом (вкл. > 0.5, выкл. < 0.3). Чтение — по `trackTime` с линейной интерполяцией.

## Анимация (`src/render/CatSprite.logic.ts`)

Конфиг анимации — часть конфига кота (`anim`):

```ts
interface CatAnimConfig {
  squash: number                 // 0.05..0.25
  axis: 'x' | 'y'
  frameMode: 'none' | 'momentary' | 'latch'
  frames: string[]               // имена кадров: ['body'] или ['closed', 'open']
  breathe?: number               // по умолчанию 0.015
}
```

- Squash & stretch с сохранением объёма, опора у ног (`anchor (0.5, 1)`).
- `none` — всегда `frames[0]`; `momentary` — `frames[1]`, пока onset; `latch` — каждый новый onset переключает кадр по кругу.
- Дыхание, когда амплитуда < 0.05: кот с паузой в партии «ждёт свой выход».
- Та же математика используется для марионетки помощника (`Puppet`), только амплитуду даёт «голос», а не трек.

## Память

Браузер хранит декодированный звук несжатым: ~21 МБ на минуту стерео 44,1 кГц. Бюджет — **≤ 200 МБ** декодированного звука на всю игру. Песня 68 с × 8 стемов стерео ≈ 200 МБ, поэтому басовые партии (бас, кик, тыква) экспортируются в моно. При загрузке движок пишет в консоль суммарный объём декодированного звука.

## Форматы

OGG (основной) + MP3 (запасной для Safari, выбирается по `canPlayType`). Заглушки — WAV.
