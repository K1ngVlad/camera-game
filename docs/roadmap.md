# План работ

MVP — законченная игра из пяти котов со сценой и сохранением. Коты 6–8 добавляются по одному, и каждого можно отрезать без вреда для остального.

## Этапы

| # | Этап | Результат | Задача |
| --- | --- | --- | --- |
| 1 | Техническое ядро | синхронные стемы, огибающие, пружинящие коты в песочнице | [01-engine-core](tasks/01-engine-core.md) |
| 2 | Скелет игры | экраны, store, сохранение, диалоги, попап, сетка камер, микшер по матрице | 02 (будет) |
| 3 | Коты 1–3 и сцена | первый полный проход до открытия сцены | 03 (будет) |
| 4 | Коты 4–5 | УФ, блэкаут, хор — **MVP готов** | 04 (будет) |
| 5 | Полировка | фильтры камер, SFX, баланс, подсказки, плейтест, сборка на itch.io | 05 (будет) |
| 6 | Коты 8 → 6 → 7 и расширения | Bongo Cat, трубач, Pop Cat, CattleCat, интерактивная сцена | 06+ |

Арт и музыка идут параллельно с первого дня; код до их готовности работает на заглушках.

## MVP

- [ ] Меню, офис, камеры, сцена, переходы
- [ ] Диалоги помощника и попап находки
- [ ] Сетка камер с блокировкой и помехами
- [ ] Микшер стемов, матрица громкости, музыкальные часы
- [ ] Огибающие и деформация котов, режимы кадров
- [ ] Клаксон и УФ

## Риски

| Риск | Что делаем |
| --- | --- |
| Музыка не успевает | сначала тройка drums + bass + keys, остальное на заглушках |
| Восемь котов не влезают | режем с конца списка |
| Звук в Safari / iframe itch.io | проверить на этапе 1: форматы, автозапуск, шов лупа |
| Игрок не понимает загадку | трёхступенчатые подсказки, плейтест на постороннем |
| Много работы художнику | котята — один спрайт, фоны — заливки, интерфейс — CSS |
