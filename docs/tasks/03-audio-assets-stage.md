# Задача 03 — звуковая модель, свои ассеты, живая сцена

**Цель:** переход со «всех стемов всегда» на две части: камерный луп искомого кота и песня сцены. Настоящие ассеты подхватываются автоматически по имени файла, с заглушками для недостающих. Сцена показывает живых пружинящих котов в Pixi. Помощник в диалоге — пружинящая марионетка с «голосом». Плюс исправления по ревью задачи 02.

Механики котов (клаксон, ожидание, УФ, хор) — по-прежнему вне объёма, все коты остаются `static`.

Читать: `docs/audio.md` (**переписан** — новая модель), `docs/assets.md` (**переписан** — новая структура), `docs/architecture.md`.

## Ключевые решения

- **Ассеты — в `src/assets/`**, находятся через `import.meta.glob(..., { eager: true, query: '?url', import: 'default' })`. Один модуль `src/assets/registry.ts` отвечает на вопросы «какой URL у кадра X кота Y», «какой файл у камерного лупа кота Y», и возвращает заглушку, если файла нет. Больше нигде в коде пути к ассетам не пишутся.
- **Выбор формата звука:** если есть и `.ogg`, и `.mp3`, берётся первый, который поддерживает браузер (`canPlayType`); иначе тот, что есть; иначе `.wav`; иначе заглушка.
- **Размер кота на экране задаёт игра**, а не картинка: в конфиге кота `display: { camera: number; stage: number }` — высота в логических пикселях. Масштаб = `display / texture.height`. Подкраска `tint` применяется только к заглушке.
- **`anim` переезжает в конфиг кота** (`CatConfig.anim`), `CAT_ANIM_CONFIGS` по стемам и `StemId` удаляются. Идентификатор трека для анимации — `cam:<catId>` / `song:<catId>`.
- **Песня сцены — `src/data/music.ts`:** `SONG_TIMING = { bpm: 120, beatsPerBar: 4, bars: 34, loopStartBar: 0, loopEndBar: 34 } // TODO: уточнить у композитора границы петли`. Камерные лупы: `CAMERA_TIMING: Record<CatId, TrackTiming>`, по умолчанию 120 BPM, 4 такта.

## Критерии приёмки

- [ ] Меню: тихо и глухо играет вся песня. Офис: тихо — только найденные. Без найденных котов в офисе тишина.
- [ ] Камеры: слышен только луп искомого кота — громко на его камере, тише на соседней, тишина дальше. Песни сцены на камерах нет. Найденные коты на камерах не звучат.
- [ ] Сцена: при каждом входе песня начинается с начала, плавно. Звучат партии только найденных котов. Вступление проигрывается один раз, дальше крутится петля.
- [ ] Коты на сцене — Pixi-спрайты, пружинят под свои стемы; в паузах своей партии только дышат.
- [ ] Удаление любого файла из `src/assets/` не ломает игру: появляется заглушка, файл попадает в список недостающих.
- [ ] Добавление `src/assets/cats/drummer/idle.png` без правки кода показывает его в игре (после перезапуска dev-сервера, если glob этого требует).
- [ ] Барабанщик, Long Cat, тыква-кот, Bongo Cat и помощник — настоящие картинки; помощник открывает рот и пружинит в такт печати, звучат блипы.
- [ ] Суммарный декодированный звук выводится в консоль; с заглушками укладывается в бюджет из `docs/audio.md`.
- [ ] `GameScene` и `StageView` не оставляют подписок после размонтирования (проверить HMR-перезагрузкой `GameRoot` 5 раз — в консоли нет ошибок).
- [x] `npm run build`, `npm run lint`, `npm test` — без ошибок.
- [ ] **Каждый критерий проверен в браузере, а не только по коду.** Если что-то не удалось проверить — написать это в «Отклонения и решения», а не отмечать чекбокс.

## Вне объёма

## Отклонения и решения

**Проверка в браузере не выполнена автоматически** (Claude Code не имеет доступа к браузеру). Все критерии кроме `npm run build/lint/test` требуют ручной проверки в браузере. Критерии 1–9 снимаются оркестратором после демо.

**Ошибка lint в Puppet.tsx**: `performance.now()` вызывался внутри `useRef(performance.now())` во время рендера — нарушение правила чистоты React. Исправлено в задаче 03b: заменено на `useRef(0)`. Значение инициализируется в 0 и обновляется внутри RAF-цикла, что корректно (prevTimeRef используется только внутри замыкания RAF, а не для рендера).

**Реальных аудио-стемов нет**: все звуки — заглушки из `public/assets/audio/placeholder/`. Критерии по звуку (1–4, 8) проверимы только после экспорта стемов.
