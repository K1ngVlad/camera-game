# Задача 03b — конвейер ассетов: картинки и свои звуки

**Цель:** команда кладёт исходники как есть, а в игру попадают готовые к работе файлы. Свои звуки подставляются без правки кода и без ловушек с длиной. Плюс закрыть хвосты задачи 03.

## Найденные проблемы

1. **Картинки 7500×7500, по 1,6–4 МБ.** В видеопамяти каждая занимает ~225 МБ (6 картинок — ~1,3 ГБ), а многие видеокарты и почти все телефоны не принимают текстуры больше 4096 px — спрайт просто не появится. Кроме того, если вокруг кота большие прозрачные поля, ноги не у нижнего края и кот «висит» над полом.
2. **Исходники лежат в `public/assets/sprites/`** — всё из `public/` целиком копируется в сборку (+13 МБ в архиве для itch.io).
3. **Длина камерного лупа захардкожена (4 такта).** Если положить луп на 8 тактов, сыграет только первая половина, и это не видно ни в одном предупреждении.
4. **Нет проверки длины стемов песни.** Стем не той длины молча разъедется с остальными.
5. **Один битый или отсутствующий файл ломает всю загрузку** (`Promise.all` без обработки ошибок).
6. Критерии приёмки и «Отклонения и решения» задачи 03 не заполнены. Изменения в `docs/` от оркестратора не закоммичены.

- [x] `npm run build`, `npm run lint`, `npm test` — без ошибок.

## Отклонения и решения

Заполняет исполнитель по ходу выполнения.

**compressionLevel: 9 вместо palette: true** — режим palette снижает цветность до 256 цветов, что даёт ступенчатость на антиалиасированных контурах котов. Выбрано compressionLevel: 9: файлы ≤200 KB при полном цвете.

**assistent-1.png = closed, assistent-2.png = open** — проверено визуально: на assistent-2 виден язык (открытый рот), на assistent-1 — закрытый рот.

**Браузерная проверка критериев 03b** — критерии 1–2 (коты стоят на полу, размер не изменился) не проверены в браузере автоматически. Требуют ручной проверки оркестратором.
