# Purr-veillance

Браузерная игра для геймджема (тема — «Камеры наблюдения»). Игрок — менеджер кошачьей группы: ищет разбежавшихся котов-музыкантов по камерам наблюдения и собирает их на сцене, где общий трек обрастает партиями. Спокойная головоломка без таймера и проигрыша.

## Как мы работаем

- **Оркестратор** (отдельный чат с Claude) ведёт дизайн, архитектуру и план и пишет задачи в `docs/tasks/`.
- **Исполнитель** (Claude Code, ты) берёт одну задачу, реализует её по шагам и отмечает чекбоксы в файле задачи.
- Если спецификация неполная или противоречит коду, выбери самое простое разумное решение и запиши его в раздел «Отклонения и решения» файла задачи. Не расширяй объём задачи по своей инициативе.
- Один подшаг задачи — один коммит. Сообщения коммитов на английском, в повелительном наклонении (`Add audio engine with synced stems`).
- Задача закрыта, когда выполнены все критерии приёмки, `npm run build`, `npm run lint` и `npm test` проходят без ошибок.

## Стек

- **Vite + React 19 + TypeScript.** React — весь интерфейс: экраны, кнопки, диалоги, попапы.
- **Jotai** — состояние; прогресс через `atomWithStorage` в localStorage. Движок читает store вне React через `getDefaultStore()` / собственный store.
- **PixiJS v8 + pixi-filters** — только два холста: изображение камеры и сцена. Деформация котов, клики по ним, фильтры камеры (шум, CRT, УФ).
- **Web Audio API без библиотек** — синхронные стемы, громкость и фильтр на каждый стем, SFX.
- **Vitest** — тесты чистой логики (огибающие, часы, поведения котов, прогрессия).
- Phaser, Tone.js, Howler и `@pixi/react` **не используем** (причины — в `docs/architecture.md`).

## Правила кода

- TypeScript строгий. В `tsconfig` включены `erasableSyntaxOnly` и `verbatimModuleSyntax`: **никаких `enum`, `namespace` и parameter properties**; используй union-типы строк и `as const`; импорт типов — через `import type`.
- Логика игры — чистые функции без Pixi, React и Web Audio, чтобы их можно было тестировать.
- Pixi-приложение создаётся один раз в компоненте-хосте через `ref` и работает императивно. Не рендерить кадры через ре-рендеры React.
- Каждое изменение громкости — через `setTargetAtTime`, без резких скачков.
- `AudioContext` создаётся/возобновляется только по жесту пользователя.
- Идентификаторы котов, стемов и камер — строки/числа из `src/data/`, а не магические значения в коде.
- Код, комментарии и имена — на английском. Тексты интерфейса и реплики — на русском, хранятся в `src/data/`.
- Пути к ассетам — относительные (`base: './'` в Vite), игра должна работать в iframe на itch.io.
- Не добавлять зависимости сверх стека без записи в «Отклонения и решения».
